## 🌱 About RigenFarms

RigenFarms is a community‑driven initiative promoting **climate‑smart agriculture** through innovative **wicking container gardening**. We work with schools, smallholder farmers, and youth groups to build food‑secure, water‑efficient gardens across Kenya.  

This website serves as our digital home – sharing our mission, projects, volunteer opportunities, and ways to partner or donate.

## 🚀 Features

- Responsive, mobile‑first design  
- Interactive hero slideshow
